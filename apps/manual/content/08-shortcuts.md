# Keyboard shortcuts

## Global / window manager

| Input | Action |
|-------|--------|
| Mouse | Focus, drag title, resize edges/corners, minimize/maximize/close |
| Desktop icons | Click launch; drag reposition |
| Taskbar chip | Focus or restore |
| Alt+Tab | Cycle focus |
| Alt+Space | Start menu (often stolen by host; remappable) |
| **F10** / **Ctrl+Esc** | Start menu (preferred) |
| Alt+Arrows | Move window |
| Alt+Shift+Arrows | Resize window |
| Alt+Ctrl+Arrows | Snap half desktop (repeat side = restore) |
| Ctrl+W | Close focused |
| Ctrl+M | Minimize focused |
| Ctrl+Q | Quit Desk |

## Terminal / selection

| Input | Action |
|-------|--------|
| Wheel | Scrollback (or app scroll) |
| Shift+PgUp / PgDn | Scrollback page |
| Drag / Shift+drag | Select text |
| Ctrl+Shift+C | Copy selection |
| Middle-click / Ctrl+V | Paste |
| Ctrl+Shift+F | Find in scrollback (host may steal this) |
| F3 / Alt+/ | Find in scrollback (preferred) |
| **F8** | Copy-mode — keyboard scrollback selection (hjkl/arrows, Space/v select, Enter/y copy) |

## Manual reader

| Input | Action |
|-------|--------|
| ↑↓ / PgUp / PgDn / wheel | Scroll chapter |
| ←→ | Previous / next chapter |
| Click TOC | Jump to chapter |
| Home / End | Top / bottom of chapter |

## Start menu (keyboard)

↑↓ select, → or Enter open submenu / activate, ← or Esc back.
